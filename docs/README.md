# 🏛️ Investment DAO

DAO d'investissement avec délégation de vote et système de réputation.

## 🚀 Installation Rapide
```bash
npm install
npx hardhat compile
npx hardhat test
```

## 📚 Documentation

- [Guide de Configuration](docs/SETUP.md)
- [Fonctionnalités Avancées](docs/ADVANCED_FEATURES.md)

## 🎯 Démarrage

### 1. Déploiement Local
```bash
# Terminal 1
npx hardhat node

# Terminal 2
npx hardhat run scripts/deploy-advanced.js --network localhost
```

### 2. Interaction
```bash
# Voir les commandes disponibles
npx hardhat run scripts/interact-advanced.js
```
